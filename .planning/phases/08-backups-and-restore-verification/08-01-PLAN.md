## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker → pg tooling (child process) | connection credentials cross into pg_dump/robocopy child processes on the host |
| worker → Redis (BullMQ) | job payloads are persisted in Redis and survive restarts |
| worker → BACKUP_DIR / BACKUP_OFFSITE_DIR filesystem | config-supplied directories and system-generated filenames drive file create/delete/copy |
| scheduled job → unattended host | no operator is watching; hangs and prompt-loop failures must fail closed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Information Disclosure | pg_dump child invocation (backup.ts) | high | mitigate | Credentials reach the child only via the env option (DATABASE_URL/PGPASSWORD), never in argv; --no-password makes a missing credential fail fast instead of prompting; argv arrays only, no shell strings |
| T-08-02 | Information Disclosure | BullMQ job payload (createBackupWorker in jobs/backup.ts) | high | mitigate | BackupJobData carries { trigger } only; unit test asserts the enqueued payload shape so no connection string can ever be persisted in Redis |
| T-08-03 | Tampering | BACKUP_DIR/offsite filename handling (backup.ts) | medium | mitigate | Filenames are system-generated from the UTC timestamp; config supplies only absolute directories; prune and copy never accept caller-supplied names; deletion is bounded to the dump naming pattern |
| T-08-04 | Denial of Service | unattended pg_dump/robocopy (backup.ts) | medium | mitigate | --no-password on pg tools; bounded robocopy retries /R:2 /W:5 instead of the effectively-infinite defaults; exec timeout on every child so a hang records FAILED and frees the worker slot |
| T-08-05 | Information Disclosure | rotation ordering (pruneBackupRetention) | high | mitigate | Pruning runs only after the new dump is renamed into place; a failed dump records FAILED and deletes nothing (locked decision D-02) |

| T-08-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan installs no packages (stdlib + Windows robocopy + docker CLI + existing bullmq/Zod/pg stack); the package-legitimacy gate is vacuously clean — any executor attempt to add a dependency is a defect |
</threat_model>
