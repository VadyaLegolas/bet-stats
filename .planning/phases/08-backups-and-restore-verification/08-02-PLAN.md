## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| worker → Docker CLI | the drill starts, waits on, and destroys containers on the operator host |
| worker → restored throwaway database | untrusted-as-in-dump content is restored and then queried |

| drill receipt → PostgreSQL | the append-only receipt is the durable trust anchor for Plan 03's green state |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-07 | Information Disclosure | pg_restore / Prisma CLI children (backup-drill.ts) | high | mitigate | DATABASE_URL and passwords pass only via child env, never argv; every invocation is an argv array with an explicit -U argument; --no-password on pg tools |
| T-08-08 | Denial of Service | fail-closed drill states (backup-drill.ts) | high | mitigate | Docker spawn failure ⇒ UNVERIFIED receipt; any step/check failure ⇒ FAILED; overall is VERIFIED only when every executed check passed (D-11) — the receipt can never silently pass |
| T-08-09 | Tampering | dump selection (backup-drill.ts) | high | mitigate | The drill restores only the newest local self-produced dump matched by the system-generated naming pattern; off-host copies are never drill inputs, so a poisoned share cannot become a green receipt |
| T-08-10 | Denial of Service | throwaway container lifecycle (backup-drill.ts) | medium | mitigate | Owned-unique container name, rm --force in a finally block, per-child exec timeouts; a removal failure is recorded as containerCleanup FAILED, not hidden |
| T-08-11 | Tampering | BackupRun / BackupVerificationReceipt rows | high | mitigate | Frozen triggers raise on UPDATE/DELETE; tests/integration/mutation-rejection.test.ts proves rejection for both tables (append-only discipline of locked decision D-12) |
| T-08-12 | Information Disclosure | checks JSON and stderr excerpts (backup-drill.ts) | medium | mitigate | Excerpts are length-bounded and passed through redactSecrets before persistence; the checks JSON stores counts, outcomes and safe reason codes only |
| T-08-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages (docker CLI, Prisma CLI, existing pg driver); the package-legitimacy gate is vacuously clean — any executor dependency addition is a defect |
