## Выбор версии и сохранение текущей модели

| Option | Description | Selected |
|--------|-------------|----------|
| DC как opt-in, V1 остаётся дефолтом | Новую версию включают вручную после бэктеста | |
| DC как дефолт сразу, V1 выбираема | Новые прогнозы сразу под DC; откат переключением версии | ✓ |
| Заменить V1 без сохранения | Удалить/переписать Poisson-путь | |

**User's choice:** «определи сразу новую модель дефолтом, а старую оставь чтобы можно было в случае чего ее выбрать»; ранее — «сделай чтобы теперешняя модель анализа тоже сохранилась».
**Notes:** V1 обязана остаться first-class: неизменяемые снапшоты, рабочий путь расчёта, участие в когортах и бэктестах.
