<objective>
Добавить в ответы API прогнозов состояние калибровки по рынкам (CALIB-01, CALIB-04): `rawProbabilities` рядом с `calibration { state, calibratedProbabilities?, calibratorVersion?, sampleSize?, requiredSample?, reasonCode? }`, вычисляемое при чтении по действующему калибратору с точно такой же закреплённой идентичностью (CALIB-02).

Purpose: это единственная граница, через которую калибровка достигает пользователя. Замороженные снимки и квитанции не меняются (D-08), сырой прогноз остаётся источником истины, а любой сбой или несовпадение идентичности показывается как UNAVAILABLE, а не как «откалибровано».
Output: функция обогащения ответа, подключённая в `ForecastsService`, модульный и интеграционный наборы.

Закрываемые решения: D-06 (идентичность при чтении), D-08 (пост-обработка при чтении, замороженное не меняется, value по сырым), D-11 (форма и состояния ответа).
</objective>
