<objective>
Add windowed (bulk) fixture backfill and a production results-sync service so forecasts run on real team statistics.
Purpose: the database has zero team statistics — no past provider fixtures locally and no production path that ingests match results. The replay path is unusable for backfill (one provider call per day per league, 460+ calls; replay policy allows 10 calls/day provider-wide), so this task adds a bounded-window fixture sync (~40 provider calls for a season) plus a results-sync route that keeps statistics flowing after each matchday and enqueues settlements.
Output: shared result persistence in @bet-stats/database, date-window fixture sync on the existing manual sync route, a new results-sync route with capability/budget gates, RESULTS capability rows from the seed script.
</objective>
