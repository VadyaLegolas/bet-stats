### Auto-fixed / executor adjustments
**1. [Rule 3 - Blocking] next/font requires literal options**
- **Issue:** a shared `sansFallback` constant in fonts.ts is rejected by the next/font SWC transform (options must be literals).
- **Fix:** the fallback list is repeated inline in each localFont call; comment explains why.
- **Files:** apps/web/app/fonts.ts (d673512)

**2. [Rule 2 - Reflow] Hero inline padding on small screens**
- **Issue:** the plan's `.home-hero` padding "48px 40px" on mobile would leave about 240px of content at 320px width, breaking the 320px reflow goal (UX-01, UD-07).
- **Fix:** mobile uses `.home-inner`'s 16px inline padding (block 48px); from 768px the plan's 72px 56px applies.
- **Files:** apps/web/app/globals.css (7a06fef)

**3. [Rule 3 - Task 1 gate] Legacy font variable in two CSS rules**
- **Issue:** `.release-brand` and `.principle-number` still referenced the removed `--font-serif`, which would fail Task 1's negative gate before Tasks 2/3 rewrote them.
- **Fix:** both pointed to `--font-heading` in Task 1; the principle rule was removed in Task 3.
- **Commit:** d673512

**4. Build artifact reverted**
- `next build` with NEXT_DIST_DIR rewrote `apps/web/next-env.d.ts` to point at `.next-gate`; reverted with `git checkout -- apps/web/next-env.d.ts` after each build, never committed.
