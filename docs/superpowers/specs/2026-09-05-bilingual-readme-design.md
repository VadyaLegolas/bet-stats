# Дизайн двуязычного README

## Цель

Добавить в корень репозитория единый `README.md` на русском и английском языках,
который одинаково полезен пользователям продукта и разработчикам.

## Структура

Русский раздел будет первым и включит описание платформы, возможности,
ответственное использование, статус MVP, стек, структуру монорепозитория,
требования, запуск через Docker и pnpm, переменные окружения, тестирование,
ограничения и дорожную карту.

Английский раздел повторит ту же информацию с эквивалентными командами и
терминами, чтобы README оставался самодостаточным для международных участников.

## Источники истины

Команды и пути сверяются с `package.json`, `pnpm-workspace.yaml`, `turbo.json`,
`infra/docker-compose.yml`, приложениями, worker-пакетом и текущими GSD-артефактами.
Неподтверждённые инструкции, секреты, реальные credentials и несуществующая
лицензия в README не добавляются.

## Проверка и публикация

После написания README выполняется самопроверка ссылок, команд, путей и отсутствия
секретов. Изменение фиксируется атомарным commit в отдельной ветке и отправляется
в GitHub через Pull Request.
